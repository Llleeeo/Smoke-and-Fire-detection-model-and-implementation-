# Final-report evidence archive

This directory contains the verified internal evidence selected for the URIS Completion Report. It freezes the completed Windows GPU state as of 18 August 2026.

## Reading order

1. `EXPERIMENT_STATUS.md`: completed stages and evidence boundaries.
2. `METRICS_SUMMARY.md`: validation, internal-test, and factorial contrast tables.
3. `REPORT_RESULTS_DRAFT.md`: cautious report-ready interpretation.
4. `RUN_REGISTRY.csv` and `INTERNAL_RESULTS.csv`: canonical machine-readable records.
5. `CHECKPOINT_MANIFEST.csv` and `DATASET_MANIFEST.csv`: data and checkpoint provenance.
6. `LIMITATIONS.md` and `REPRODUCIBILITY.md`: interpretation and rerun constraints.

## Evidence boundary

The formal 3-seed x 4-condition factorial matrix and fixed internal-test evaluation are included. Historical development experiments and later exploratory work are preserved only in the `archive/pre-final-report-20260820` branch.

Figures are derived from the retained tables and summaries. Missing metrics are recorded as `NA`, never as zero.
