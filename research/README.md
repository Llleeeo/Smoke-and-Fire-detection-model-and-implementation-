# Research evidence

This directory contains the research process and results selected for the URIS Completion Report.

## Process records

- [`EXPERIMENT_LOG.md`](EXPERIMENT_LOG.md): chronological record from dataset restoration through factorial dataset preparation and formal internal evaluation.
- [`ONTOLOGY_AUDIT_GUIDELINES.md`](ONTOLOGY_AUDIT_GUIDELINES.md): frozen semantic decision rules used for the annotation audit.

## Final internal evidence

The [`final_report_evidence/`](final_report_evidence/) directory contains:

- validation and internal-test statistics;
- the A/B/C/D run registry;
- dataset and checkpoint manifests;
- report-ready interpretation and limitations;
- internal-only figures suitable for the Completion Report.

The report evidence stops after the completed internal factorial evaluation. Superseded development experiments and later exploratory work remain available in the archive branch.
